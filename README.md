# phasecut — 图像相位展开的残差切口模块

二维包裹相位（wrapped phase）的**残差切口（residual / branch-cut）展开**。
在 ≤32×32 的包裹相位与有效像素 mask 上：定位每个 2×2 环路的整数残差电荷，
把异号电荷按**非负边权最短路径**配对、剩余电荷连到图像外边界，路径经过的
像素边置为不可跨越的切口，再在每个切口连通区内从字典序最小像素洪泛展开。
可选的逐像素**可靠度**让切口优先走低可靠走廊：每条对偶步边权为
`1 + 两端像素可靠度之和`；不传可靠度时边权恒为 1，即原曼哈顿最短路语义。
结果把数据矛盾（涡旋）显式放到切口和 `unmet_edges` 里，**不用看似平滑的
展开结果掩盖 ±2π 的环矛盾**。

- Python：**3.14.7**（3.10+ 的语法也可运行，但按 3.14.7 验收）
- 依赖：**仅 Python 标准库**（`math`、`collections`、`typing`）。装好 Python 后
  无需安装任何其他东西；核心、测试、演示全部离线、确定性运行。
- 规模上限：高、宽均 **≤ 32**（`phasecut.MAX_SIZE`）。

## 运行

```bash
./.venv/bin/python -m unittest discover -s tests -v   # 必要测试（38 个用例，含确定性 fuzz 与小图路径枚举）

```

两条终端命令即全部入口；没有网站、CLI 产品、服务或后台任务。

## 接口

```python
from phasecut import unwrap_phase, wrap_phase

result = unwrap_phase(
    phase, mask, *, search_budget=1_000_000, reliability=None
)
```

- `phase`：行序列的行序列，每个元素为 `int`/`float`（拒绝 `bool`、`complex`、
  字符串），必须**有限**（拒绝 NaN/±Infinity）且落在 **[-π, π)**。
  任意相位可用 `wrap_phase(x)` 先包裹。
- `mask`：与 `phase` 同形的 `bool` 行序列；`True` 为有效像素。
  `0/1` 等整数**不**被静默当作布尔值。
- `search_budget`：正整数 `int`（拒绝 `bool`、浮点、≤0）。单次对偶图 BFS
  允许访问的最大节点数（单位权 BFS 与加权 Dijkstra 共用同一预算口径）。
- `reliability`：可选关键字参数。与 `phase` 同形的数值行序列；每个元素为
  `int`/`float`（拒绝 `bool`、`complex`、字符串），必须**有限且 ≥ 0**
  （拒绝 NaN/±Infinity/负数，非法值带 `row/col` 定位）。逐像素可靠度只影响
  切口路径的边权，不参与残差计算、不做跨帧/跨区相位跟踪。无效（mask 外）
  像素的可靠度也必须提供合法值（可填 0），但不参与任何边权。缺省 `None`
  表示所有像素可靠度为 0。
- 纯函数：不修改 `phase` / `mask`；成功才返回，失败即抛异常，不存在
  “部分切口已生成”的部分结果。

返回不可变的 `UnwrapResult`：

| 字段 | 含义 |
|---|---|
| `residues` | `Residue(row, col, charge)` 元组，按 `(row,col)` 字典序；`(row,col)` 为 2×2 环左上角，`charge` 为包裹邻差环和 /(2π) 的最近整数（典型 -1/0/+1）。 |
| `cuts` | `CutEdge(row1,col1,row2,col2)` 元组，字典序；四邻接有效像素边，端点已按字典序排列。洪泛时不可跨越。 |
| `regions` | `Region(anchor, baseline, pixels, offsets)` 元组，按 `anchor` 排序。每个切口连通区从字典序最小像素 `anchor` 洪泛；`baseline` 恒为 `0`（锚点整数偏移基准），`pixels` 字典序排列，`offsets[i]` 为对应整数 k，展开值 = 包裹值 + 2π·k。 |
| `unwrapped` | 与输入同形的嵌套元组；无效像素位置为 `None`。 |
| `unmet_edges` | `UnmetEdge(..., residual)`：所有**非切口**有效边中，展开差与包裹邻差不一致超过口径的边，按字典序。常规矩形数据为空；当整数卷绕绕 mask 洞、或落在两侧均无完整 2×2 环的“不可切口边”上时非空——该矛盾不归属于任何可计算残差的环、无法用切口表示，按契约如实报告而非掩盖。 |

### 错误语义（固定、可定位、不静默纠正）

| 异常 | 触发条件 |
|---|---|
| `InvalidPhaseInputError` | 结构/类型/数值非法。带 `row`/`col`（结构错误时可能为 `None`），如 NaN 在 `(3,2)`。是 `ValueError` 子类。 |
| `UnwrappingContradictionError` | 防御性异常：某个全有效 2×2 环的包裹邻差环和不在 2π 整数倍口径内。对**任何真正落在 [-π,π) 的输入**，四点包裹差之和由望远镜相消恒等式必为 2π 的整数倍（浮点散布 ~1e-15），故合法输入实际不会触发；保留它以固定契约并防御未来非标准来源数据。 |
| `SearchBudgetExhausted` | 最短路搜索新访问格点数达到 `search_budget`，**搜索没算完**。 |
| `NoSolutionError` | 最短路搜索**完整**跑完后，剩余残差既无可达异号电荷、也无有效路径到图像外边界（如被无效海围困的孤岛涡旋）。这是已证明的无解。 |

`SearchBudgetExhausted`（不知道有没有解）与 `NoSolutionError`（证明无解）
是两个不同异常，绝不混用。`demo.py` 4c 用同一输入分别演示两者。

## 算法与设计取舍

1. **残差**：每个四点全有效的 2×2 环，取逆时针四条包裹邻差
   `wrap(v_next-v)` 之和；除以 2π 四舍五入得整数电荷。
2. **对偶图**：环格 = 高 (H-1)×宽 (W-1) 的格点；从环格向北/东/南/西移动
   一步，跨过一条两端均为有效像素的像素边（曼哈顿四方向）。每条对偶步
   （像素边 `a-b`）的**非负边权**固定为
   `EDGE_BASE_WEIGHT(=1) + reliability[a] + reliability[b]`。因此：
   - 配对路径代价 = 沿途像素边权之和；边权恒为 1 时就是曼哈顿步数；
   - mask 的无效像素会阻断相应对偶步（绕路）；
   - 对偶格只有在存在有效 2×2 环时才可停留——**1 像素宽的细脖子不含
     环格，任何切口都无法穿过它**（见“已知限制”）。
3. **配对（第一遍）**：残差按 `(row,col)` 字典序处理（**可靠度不改变电荷
   处理顺序**）；对每个未配对残差在非负权对偶图上做 Dijkstra，在当前未配对
   异号残差中选**路径代价最小**者，同代价取目标坐标字典序最小者；同一目标
   的同代价路径按固定方向序（北=0、东=1、南=2、西=3）的方向序列字典序决胜。
   单位权下该决胜与原固定邻接序 BFS 的首次到达路径逐边相同，故不传可靠度时
   结果与加权扩展前完全一致。
4. **连外边界（第二遍）**：仍未配对的残差各做 Dijkstra，找“格内路径 +
   一步跨出图像外边界”的最小总代价出口；同代价按出口格字典序、再按该步
   方向序决胜。路径边全部加入切口。**mask 的洞不是外边界**；找不到出口即
   `NoSolutionError`（几何结论，与权重无关）。
5. **洪泛展开**：删掉切口边后，每个有效像素连通区从字典序最小像素起
   DFS，锚点整数偏移 `k=0`，邻点 `k = round((φ_me+wrap(w_nb-w_me)-w_nb)/2π)`。
6. **一致性复核**：对全部**非切口**有效边重算
   `residual = (φ_b-φ_a) - wrap(w_b-w_a)`，超口径者进 `unmet_edges`。
   正常残差（落在四点全有效环上）在正确切口布线下非切口边残差全为 0；
   但当整数卷绕绕在 mask 的洞上、或落在两侧均无完整 2×2 环的边上时，
   该矛盾不归属于任何可计算残差的环、也无法表示为对偶路径上的切口，
   此时相应边进入 `unmet_edges`（残差为整数个 2π），照实报告，
   不做平滑、不做全局 2π 对齐。

**取舍说明**：配对是题面指定的字典序贪心 + 最短路（可选非负边权），**不是
全局最优（最小总切口代价）的电荷平衡算法**；贪心可能不是总代价最小的布设法，
但结果确定、可复现、可独立核验，且保证非切口边一致。各区锚点基准固定
为 0，因此**区与区之间可能相差任意整数个 2π**，本模块不做跨区/全局相位
对齐（题面未定义外部基准）。

## 浮点误差口径

- 残差判定口径 `RESIDUE_TOLERANCE = 1e-9 rad`：环和与最近 2π 整数倍的
  偏差超过它才报 `UnwrappingContradictionError`。
- 边一致性口径 `UNWRAP_TOLERANCE = 1e-9 rad`：非切口边残差超过它才进
  `unmet_edges`。
- 这是**严格**口径，不是用来掩盖边界错误的宽容差：32×32 内四点包裹差与
  任意长度路径的浮点散布实测在 ~1e-13 量级（见 demo 斜坡最大偏差
  ~7e-15 rad），1e-9 留有约千倍余量；真正的 ±1·2π 矛盾（~6.28）必然暴露。
- 输入相位要求在 [-π, π)；恰为 `-π` 合法、恰为 `+π` 拒绝（半开区间边界
  不做静默折叠）。

## 已知限制

- 只实现题面契约的数学子集：矩形网格、四邻接、整数电荷 -1/0/+1 的常规
  情形、≤32×32。**不宣称**兼容任何行业相位展开标准或质量图/最小二乘/
  掩膜质量引导等完整方法。
- 1 像素宽（无 2×2 环）的 mask 通道不能承载对偶路径；两侧电荷若无法绕路
  配对或各自出界，会得到 `NoSolutionError`。这是对偶图几何的如实结论，
  测试以 2 行宽走廊验证可通行情形。
- mask 内部的洞可携带整数卷绕（如涡核恰好落在被挖掉的像素上）。该卷绕
  不落在任何四点全有效的环上，残差检测不到、切口也无法表示，相应边以
  `unmet_edges`（整数个 2π）报告而非静默平滑——这是“不掩盖矛盾”的
  直接体现，确定性用例与 200 例随机 fuzz 均有覆盖。
- 贪心配对不保证切口总代价全局最小。
- 可靠度只改变路径边权（`1 + 两端之和`），不改变残差位置、电荷处理顺序、
  切口禁令语义或逐边一致性复核；不存在“可靠度为 0 就允许跨无效边/掩盖矛盾”
  的通道。不做跨帧可靠度传播或相位跟踪——可靠度必须逐帧由调用方提供。
- 同代价判定使用 IEEE 浮点精确相等比较；边权是有限 int/float 的一次加法
  与累加，构造相同的边给出完全相同的浮点值，确定性不受影响。
- 不做区之间的全局 2π 对齐；`baseline` 恒为 0。

## 文件

- `phasecut.py` — 唯一核心模块，可直接 `import phasecut`。
- `tests/test_phasecut.py` — 必要测试（38 个）。期望值由文件内的**独立**
  参考实现产生（`atan2(sin,cos)` 包裹、独立四点环和、独立 BFS/加权
  Dijkstra/拓扑复核、小图简单路径暴力枚举、解析多涡旋数据生成），不调用
  被测核心来得到期望值；`wrap` 往返一致性仅作补充断言。可靠度覆盖：
  输入校验、低可靠度走廊改道、全相等退回曼哈顿、零权参数等价、
  同代价路径方向序、被 mask 围住电荷仍报无解、加权随机逐边复核。
- `demo.py` — 固定输入：无涡旋斜坡（频繁跨 π）、单涡旋参考的切口前后
  矛盾度量、低可靠度走廊的加权改道演示，以及 NaN 拒绝、孤岛无解、
  预算耗尽三个实际触发的边界。整机运行约 0.03 秒（远低于 90 秒上限）。
